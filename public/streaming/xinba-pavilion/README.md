# Xinba Pavilion streaming fixture

Original procedural geometry created specifically for this repository to validate the production Active/Proxy GLB streaming path.

- Active: 564 triangles / 376 vertices
- Proxy: 240 triangles / 160 vertices
- XVLM: 408-byte tail-only runtime lighting transport fixture
- XVLM revision: `fixture-light-v1`
- XVLM charts: 1
- XVLM fine tiles: 0
- XVLM metres per texel: 0.05
- External models: none
- External textures: none
- Clearance tag: `xinba-owned`
- Purpose: engineering acceptance fixture, not final shipping art

The GLBs and XVLM are intentionally compact engineering fixtures. They prove binary asset transport, Active/Proxy scene ownership, provenance gating and chunk-lighting package registration.

They do not claim final visual quality and were not authored through Blender because no Desktop Commander device was connected during this checkpoint. The first Blender/Hunyuan3D-authored production-quality asset will use the same manifest, GLB and XVLM runtime contracts.
